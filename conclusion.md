# Conclusion

## Project Summary

This project successfully demonstrated the deployment of a Wazuh Security Information and Event Management (SIEM) environment using Ubuntu Server, Windows 11, and Kali Linux in a virtual lab environment.

The Wazuh Manager, Indexer, and Dashboard were installed and configured successfully. Both Windows and Kali Linux endpoints were connected as active agents, enabling centralized log collection and real-time security monitoring.

Several security events were generated and analyzed, including failed logins, successful logins, file creation, file modification, file deletion, process execution, user account management, and Windows service events.

The project also demonstrated the use of Threat Hunting, File Integrity Monitoring (FIM), Discover, MITRE ATT&CK mapping, Inventory, and Vulnerability Detection modules within the Wazuh Dashboard.

This project provided practical experience in SIEM deployment, log analysis, security monitoring, and incident investigation, helping to strengthen foundational Security Operations Center (SOC) skills.
