# Threat Hunting using Wazuh SIEM

## Overview

Threat Hunting is the proactive process of searching through collected logs and security events to identify suspicious activities, unauthorized access attempts, and indicators of compromise (IOCs). Wazuh provides powerful search capabilities that allow analysts to investigate security events across all connected endpoints.

---

# Objectives

- Investigate authentication events
- Search for suspicious activities
- Analyze endpoint logs
- Detect file integrity changes
- Filter security alerts
- Improve incident investigation

---

# Accessing Threat Hunting

1. Open the Wazuh Dashboard.
2. Log in using an administrator account.
3. From the left navigation menu, select **Threat Hunting**.
4. Use the search bar to query security events.

---

# Threat Hunting Queries

## 1. Failed Login Attempts

```text
event.code:4625
```

**Purpose**

Displays all failed Windows login attempts.

**Expected Result**

- Username
- Source Host
- Timestamp
- Event ID 4625


## 2. Successful Login

```text
event.code:4624
```

**Purpose**

Displays successful Windows authentication events.


## 3. Windows Events

```text
agent.name:"Windows"
```

Displays all logs collected from the Windows endpoint.

---

## 4. Kali Linux Events

```text
agent.name:"Kali"
```

Displays all events generated by the Kali Linux agent.

---

## 5. High Severity Alerts

```text
rule.level>=7
```

Displays medium and high severity alerts.

---

## 6. Critical Alerts

```text
rule.level>=10
```

Displays high-priority security alerts.

---

## 7. File Integrity Monitoring

```text
rule.groups:syscheck
```

Displays all file integrity monitoring events.

---

## 8. Search a Specific File

```text
syscheck.path:*demo.txt
```

Displays all events related to the monitored file.

---

## 9. PowerShell Events

```text
powershell
```

Displays PowerShell-related events if collected.

---

## 10. Command Prompt Events

```text
cmd.exe
```

Displays Command Prompt execution events.
